# .agents/ai_specs

This directory stores implementation specs for AI coding agents.

## Contents

- `spec-template.md` - reusable template for future implementation specs.

## Spec Standard

Specs should be concrete enough that an agent can implement them without guessing. Include goal, scope, affected paths, constraints, acceptance criteria, and verification commands.

## Notes

Use this folder for planned or active work. Long-lived repository facts belong in `../ai_docs/`.
