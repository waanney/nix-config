# Spec Template

## Goal

Describe the exact outcome expected from the change.

## Scope

List the paths, modules, or behaviors that are in scope.

## Out Of Scope

List related work that should not be changed.

## Implementation Notes

- Describe the intended approach.
- Name important files or modules.
- Mention compatibility or migration constraints.

## Acceptance Criteria

- The expected behavior is implemented.
- Existing behavior outside the scope is unchanged.
- Relevant documentation is updated.

## Verification

```bash
nix fmt
nix flake check
```

Adjust verification commands to the actual task before using this template.
